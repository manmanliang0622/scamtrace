# Spec Delta

## Purpose

以摘要、風險時間軸、對話標註與手法統計呈現一個案例的分析結果，讓使用者看出對話在哪裡開始轉向，並提供共用版面、首頁與 165 提示。

## ADDED Requirements

### Requirement: 結果摘要
結果頁 SHALL 顯示風險等級徽章（低／中／高，以顏色加文字呈現，不只靠顏色）、整體分數、詐騙類型、判斷摘要與分析方式（模型或規則）。

#### Scenario: 高風險案例摘要
- **WHEN** 使用者開啟整體風險 81、類型 investment、以模型分析的案例
- **THEN** 摘要區顯示文字「高」的徽章、分數 81、類型「假投資」、摘要文字與「語言模型分析」

#### Scenario: 規則比對案例
- **WHEN** 案例分析方式為 rule
- **THEN** 摘要區顯示「本次使用規則比對，準確度較低」

### Requirement: 時間軸資料 API
系統 SHALL 提供 `GET /api/cases/<id>/timeline`，回傳 JSON 陣列，每筆含 seq、sent_at、speaker、risk、stage、tactics（手法代碼陣列）；存取權限與結果頁相同。

#### Scenario: 取得時間軸
- **WHEN** 案例擁有者請求自己案例的時間軸 API
- **THEN** 回傳依 seq 排序的 JSON 陣列，筆數等於訊息數

#### Scenario: 無權限
- **WHEN** 其他使用者請求該 API
- **THEN** 回 404

### Requirement: 風險時間軸圖
結果頁 SHALL 以 SVG 折線圖呈現時間軸：橫軸為訊息序號、縱軸為風險分數 0–100，背景依階段分色，轉折點以垂直線與標籤標示。滑鼠移到資料點 SHALL 顯示該則訊息摘要；點擊 SHALL 捲動到對話區中的該則訊息。

#### Scenario: 轉折點標示
- **WHEN** 案例轉折點為第 18 則
- **THEN** 時間軸在序號 18 處有垂直線與「轉折點」標籤

#### Scenario: 點擊資料點
- **WHEN** 使用者點擊序號 18 的資料點
- **THEN** 頁面捲動到第 18 則訊息並短暫標示

### Requirement: 對話區與手法標籤
對話區 SHALL 以聊天泡泡排版（我在右、對方在左），每則下方顯示手法標籤；點擊標籤 SHALL 在該則原文中標亮依據字句。訊息內容 MUST 以純文字呈現，不得被當成 HTML 解譯。

#### Scenario: 點標籤標亮依據
- **WHEN** 使用者點擊第 18 則的「稀少性」標籤，其依據為「名額只剩今天」
- **THEN** 第 18 則泡泡中的「名額只剩今天」被標亮

#### Scenario: 訊息含 HTML
- **WHEN** 某則訊息內容為 `<script>alert(1)</script>`
- **THEN** 頁面原樣顯示這段文字，不執行任何程式

### Requirement: 手法統計
結果頁 SHALL 以橫條圖顯示本案例各手法出現的次數，只列出現次數大於 0 的手法。

#### Scenario: 統計顯示
- **WHEN** 案例中 authority 出現 4 次、scarcity 出現 2 次
- **THEN** 橫條圖顯示權威 4、稀少性 2，權威的長條較長

### Requirement: 共用版面與 165 提示
每頁 SHALL 有頂部導覽列（系統名稱、我的案例、上傳、後台〔僅管理員〕、登入／登出），底部 MUST 顯示「本系統僅供參考，若有疑慮請撥打 165 反詐騙專線」。版面 SHALL 在 360 px 寬度下可正常使用。

#### Scenario: 管理員導覽列
- **WHEN** 管理員登入後瀏覽任一頁
- **THEN** 導覽列出現「後台」連結；一般使用者不會看到

#### Scenario: 手機寬度
- **WHEN** 以 360 px 寬度開啟結果頁
- **THEN** 內容不需水平捲動即可閱讀，時間軸縮放至容器寬度

### Requirement: 首頁
首頁 SHALL 說明系統用途、三步驟（上傳 → 確認去識別化 → 看分析）、隱私處理方式，並提供示範案例入口。

#### Scenario: 訪客開啟首頁
- **WHEN** 訪客開啟 `/`
- **THEN** 看到系統說明、三步驟、隱私說明與示範案例卡片

### Requirement: 上傳頁
上傳頁 SHALL 提供檔案上傳或貼上文字二擇一，並提供可展開的 LINE 匯出教學。

#### Scenario: 展開匯出教學
- **WHEN** 使用者在上傳頁點擊「如何匯出 LINE 聊天紀錄」
- **THEN** 展開匯出步驟說明
