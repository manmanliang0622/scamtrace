# Spec Delta

## Purpose

以自編示範資料與人工標註的標準答案，評估語言模型與規則比對兩種分析方式及去識別化的效果，產出可放進作品說明的初步測試結果。

## ADDED Requirements

### Requirement: 示範資料不含真實對話
示範對話 MUST 由開發者自行編寫，不得使用任何真實個人對話；情節 SHALL 參考 165 全民防騙網公開的詐騙手法說明改寫，並在系統中標示「自編示範資料」。

#### Scenario: 示範案例標示
- **WHEN** 使用者瀏覽任一示範案例
- **THEN** 頁面標示「自編示範資料」

### Requirement: 示範資料組成
示範資料 SHALL 至少 8 段：假投資、感情詐騙、網購解除分期、假冒親友借錢、假冒檢警、求職詐騙，以及 2 段正常對話（朋友約吃飯、同學討論作業）。每段 MUST 有 20–60 則訊息，並含電話、帳號等假個資。

#### Scenario: 資料檢查
- **WHEN** 執行評估腳本載入示範資料
- **THEN** 共至少 8 段、每段 20–60 則，且每段詐騙對話至少含一項假個資

### Requirement: 人工標註標準答案
每段示範資料 SHALL 有逐則人工標註（手法、階段、轉折點）與整段是否為詐騙，作為評估的標準答案。

#### Scenario: 標註完整
- **WHEN** 評估腳本讀取某段示範資料的人工標註
- **THEN** 每則訊息都有階段，整段有是否詐騙與轉折點（正常對話轉折點為空）

### Requirement: 分析方式比較
評估腳本 SHALL 對同一批示範資料分別以語言模型與規則比對分析，並輸出：整段詐騙判斷正確率（含正常對話是否誤判）、各手法的精確率與召回率、轉折點與人工標註相差的則數。

#### Scenario: 產出比較表
- **WHEN** 執行評估腳本
- **THEN** 輸出一張表，列出兩種方式的整段正確率、各手法精確率與召回率、轉折點平均誤差

#### Scenario: 沒有 API 憑證
- **WHEN** 未設定 API 憑證時執行評估腳本
- **THEN** 只輸出規則比對的結果，並註明語言模型部分未執行

### Requirement: 去識別化成功率
評估腳本 SHALL 統計示範資料中所有假個資的遮罩成功率，並列出漏遮的個資類型。

#### Scenario: 漏遮統計
- **WHEN** 示範資料共有 50 處假個資，其中 48 處被遮罩
- **THEN** 輸出遮罩成功率 96%，並列出 2 處漏遮的類型

### Requirement: 結果措辭
評估報告 MUST 將結論寫成「初步測試」，註明樣本為 8 段自編資料，不得寫成一般化結論；若因評估而調整風險權重，SHALL 記錄調整前後數值與理由。

#### Scenario: 報告措辭
- **WHEN** 評估結果整理進作品說明
- **THEN** 文字標示為初步測試並註明樣本數
